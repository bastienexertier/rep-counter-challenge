# Rep counter challenge

Count gym repetitions live from a phone's motion sensors. 168 labelled recordings of real sets, an empty detector
to fill in, and a script that scores it. Submissions are judged on recordings collected after publication.

```
python main.py --detail
```

Implement `RepDetector` in `detector.py`. Everything you need (problem, data format, interface, rules, scoring,
score to beat, how to submit) is in [AGENTS.md](AGENTS.md). Scores: [LEADERBOARD.md](LEADERBOARD.md).
